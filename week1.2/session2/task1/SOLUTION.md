# Task 1 - Solution

Start the interpreter in the terminal (on some systems it is `python3`):

```
python
```

Type each expression at the `>>>` prompt:

| Expression | Result | Why |
|---|---|---|
| `7 > 4` | `True` | 7 is greater than 4 |
| `9 < 1` | `False` | 9 is not less than 1 |
| `8 >= 3` | `True` | 8 is greater than (or equal to) 3 |
| `"hello" == "Hello"` | `False` | string comparison is case-sensitive: `h` and `H` differ |
| `"a" > "e"` | `False` | strings compare alphabetically (by character code); `a` comes before `e`, so it is "less" |

Exit with `Ctrl+D` (macOS/Linux) - or type `exit()`. On Windows it is `Ctrl+Z` then Enter.
